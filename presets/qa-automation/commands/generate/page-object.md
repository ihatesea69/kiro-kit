  - page-url-or-name

Generate a Page Object class encapsulating element locators and interaction methods.

## Process
1. Explore the page or component
2. Identify interactive elements
3. Create locator methods using proper selector strategy
4. Add action methods for user interactions
5. Include wait conditions for dynamic content
