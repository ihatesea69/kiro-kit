# Visual Regression Testing

Patterns for detecting unintended visual changes through screenshot comparison and component-level visual testing.

## When to Use This Skill

- Setting up visual regression infrastructure
- Capturing and comparing screenshots
- Managing visual baselines
- Testing responsive design across viewports
- Reducing false positives from dynamic content
