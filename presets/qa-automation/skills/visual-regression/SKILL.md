# Visual Regression Testing

Detecting unintended visual changes in web applications using automated screenshot comparison.

## When to Use This Skill

- Setting up Playwright visual comparison tests
- Configuring thresholds and handling dynamic content
- Testing across multiple viewports and themes
- Managing baseline images in version control
- Integrating visual tests into CI workflows
- Debugging and resolving visual diff failures
