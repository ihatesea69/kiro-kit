# Mobile Testing

Patterns for testing mobile applications and responsive web experiences across platforms and devices.

## When to Use This Skill

- Testing responsive web design on mobile viewports
- Automating mobile browser testing with Playwright
- Testing native mobile apps with Appium
- Validating touch interactions and gestures
- Cross-device compatibility testing
