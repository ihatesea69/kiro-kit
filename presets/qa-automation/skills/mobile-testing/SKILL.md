# Mobile Testing

Testing patterns for mobile applications and responsive web experiences across devices and platforms.

## When to Use This Skill

- Configuring Playwright mobile device emulation
- Testing touch gestures and mobile interactions
- Validating responsive layouts across breakpoints
- Setting up Appium for native mobile app testing
- Using Detox for React Native test automation
- Testing offline behavior and network conditions on mobile
