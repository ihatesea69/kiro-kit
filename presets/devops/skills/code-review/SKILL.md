# Code Review

Activate this skill when performing or receiving code reviews.

## When to Use

- Receiving code review feedback
- Completing tasks requiring review before proceeding
- Before making completion claims about implementation
- Reviewing pull requests for quality and correctness

## Practices

1. Receiving feedback: apply technical rigor over performative agreement
2. Requesting reviews: provide clear context and scope
3. Verification gates: require evidence before status claims

## Rules

- Never claim completion without running tests
- Address all critical and high-priority feedback
- Provide evidence (test output, build logs) with completion claims
- Focus on correctness, security, and maintainability
- Be constructive and specific in feedback
- Separate style preferences from correctness issues
