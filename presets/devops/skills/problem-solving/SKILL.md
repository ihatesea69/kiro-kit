# Problem Solving

Activate this skill when facing complex problems that resist straightforward solutions.

## When to Use

- Complexity spirals: problem keeps growing as you dig in
- Innovation blocks: standard approaches are not working
- Recurring patterns: same issue keeps appearing in different forms
- Scale uncertainty: unclear how solution will behave at scale
- Stuck: no clear path forward after initial attempts

## Techniques

1. Simplification Cascade: strip away complexity until core problem is visible
2. Inversion: consider what would make the problem worse, then avoid those things
3. Meta-pattern Recognition: identify the pattern behind recurring issues
4. Scale Game: test solution at 1x, 10x, 100x to find breaking points
5. Constraint Mapping: list all constraints, then question which are real vs assumed

## Rules

- Try the simplest approach first
- If stuck after 3 attempts, change the approach entirely
- Document what you tried and why it failed
- Separate the problem from the solution space
- Question assumptions before adding complexity
