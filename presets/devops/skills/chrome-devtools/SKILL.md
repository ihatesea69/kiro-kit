# Chrome DevTools

Activate this skill when you need browser automation or web performance analysis.

## When to Use

- Automating browser interactions for testing
- Taking screenshots of web pages
- Analyzing page performance metrics
- Monitoring network traffic
- Web scraping for data collection
- Form automation and testing

## Capabilities

- Page navigation and interaction
- Screenshot capture and comparison
- Network request monitoring
- Performance profiling (Core Web Vitals)
- JavaScript execution in browser context
- Cookie and storage management

## Rules

- Use headless mode for CI/CD environments
- Set appropriate timeouts for page loads
- Handle dynamic content with proper wait strategies
- Respect robots.txt and rate limits when scraping
- Clean up browser instances after use
- Use viewport settings appropriate for the test scenario
