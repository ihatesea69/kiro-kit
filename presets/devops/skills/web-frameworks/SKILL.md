# Web Frameworks

Activate this skill when building web applications or services.

## When to Use

- Setting up web application projects
- Implementing server-side rendering
- Building API services with Express or Fastify
- Configuring build tools and bundlers
- Managing monorepo structures with Turborepo

## Frameworks

- Next.js: React framework with SSR/SSG/ISR
- Express/Fastify: Node.js HTTP servers
- Turborepo: monorepo management and build orchestration

## Rules

- Follow framework conventions for file structure
- Use environment variables for configuration
- Implement proper error handling middleware
- Configure security headers (CORS, CSP, HSTS)
- Optimize for production builds
- Use TypeScript for type safety
