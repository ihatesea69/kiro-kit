# AI Multimodal

Activate this skill when you need to process or generate multimedia content.

## When to Use

- Analyzing screenshots or diagrams
- Processing PDF documents or architecture diagrams
- Generating images from text descriptions
- Extracting structured data from visual content
- Transcribing or analyzing audio/video content

## Capabilities

- Image analysis: captioning, object detection, OCR, visual Q&A
- Document processing: PDF tables, forms, charts, diagrams
- Image generation: text-to-image, editing, composition
- Audio analysis: transcription, summarization
- Video processing: scene detection, temporal analysis

## Rules

- Use appropriate model for the task (vision vs generation)
- Provide clear, specific prompts for best results
- Verify generated content for accuracy
- Respect content licensing and attribution
- Keep file sizes reasonable for processing
