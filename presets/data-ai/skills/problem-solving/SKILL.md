# Problem Solving

Activate this skill when facing complex data/ML challenges that need structured approaches.

## When to Use

- Complexity spirals in data pipelines
- Innovation blocks in model design
- Recurring patterns in failed experiments
- Scale uncertainty in data systems
- Choosing between competing approaches

## Techniques

### Simplification Cascade
Strip the problem to its simplest form, solve that, then add complexity back incrementally.

### Inversion Exercise
Instead of "how to improve accuracy", ask "what would make accuracy worse?" and avoid those things.

### Ablation Study
Remove components one at a time to identify what actually contributes to the result.

### Divide and Conquer
Split the problem at natural boundaries (data vs model vs infrastructure).

### Baseline First
Always establish a simple baseline before attempting complex solutions.

## Rules

- Define success criteria before starting
- Time-box exploration (2 hours max per approach)
- Document what you tried and why it failed
- Ask for help after 3 failed attempts
- Simple solutions that work beat complex ones that might
