# Skills

This directory contains agent skills for the data-ai preset. Each skill is a folder with a `SKILL.md` file containing front-matter and instructions.

## Available Skills

| Skill | Description |
|-------|-------------|
| google-adk-python | Google AI Development Kit for Python agents |
| ai-multimodal | Multimedia content processing with Gemini |
| document-skills | Sub-skill container for document processing (docx/pdf/pptx/xlsx) |
| research | Technology research and evaluation |
| repomix | Repository packaging for analysis |
| sequential-thinking | Structured multi-step reasoning |
| data-engineering | Data pipeline design and ETL patterns |
| ml-ops | ML model deployment and monitoring |
| jupyter-notebooks | Jupyter notebook workflows and best practices |
| pandas-analysis | Data manipulation and analysis with pandas |
| pytorch-training | PyTorch model training and optimization |
| tensorflow-keras | TensorFlow/Keras model development |
| scikit-learn | Classical ML with scikit-learn |
| debugging | Systematic debugging framework |
| problem-solving | Techniques for complexity and blocks |
| planning | Technical solution planning |
| docs-seeker | Documentation search and retrieval |
| code-review | Code review practices |
| skill-creator | Creating new skills |
| mcp-builder | Building MCP servers |
| mcp-management | Managing MCP integrations |
| template-skill | Template for creating new skills |
