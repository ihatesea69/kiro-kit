# Docs Seeker

Activate this skill when searching for documentation on data/ML libraries.

## When to Use

- Finding API references for pandas, scikit-learn, PyTorch
- Looking up function signatures and parameters
- Finding migration guides between library versions
- Searching for usage examples and tutorials
- Checking compatibility between library versions

## Process

1. Identify the library and version
2. Search official documentation first
3. Check changelog for version-specific changes
4. Look for community examples if official docs are sparse
5. Verify information is current (check dates)

## Sources Priority

1. Official library documentation
2. GitHub repository README and examples
3. Published papers (for algorithms)
4. Stack Overflow (verified answers only)
5. Blog posts (recent, from known authors)

## Rules

- Always note the library version
- Prefer official docs over third-party tutorials
- Verify code examples actually run
- Check deprecation warnings
- Report when documentation is unclear or missing
