# Planning

Activate this skill when planning data/ML technical solutions.

## When to Use

- Designing ML experiment roadmaps
- Architecting data pipeline systems
- Scoping new data science features
- Planning model migration strategies
- Estimating compute and data requirements

## Process

1. Define the problem and success metrics
2. Identify constraints (data, compute, time, team)
3. Research existing solutions and baselines
4. Design approach with clear milestones
5. Identify risks and mitigation strategies
6. Create actionable task breakdown

## Output Format

Plans should include:
- Problem statement (1-2 sentences)
- Success criteria (measurable)
- Approach overview
- Task breakdown with estimates
- Risks and mitigations
- Resource requirements

## Rules

- Start with the simplest viable approach
- Include data requirements and availability check
- Account for experiment iteration time
- Plan for failure modes and fallbacks
- Do NOT implement -- only plan and report
