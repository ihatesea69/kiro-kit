# Problem Solving

Activate this skill when stuck, facing complexity spirals, or encountering recurring issues.

## When to Use

- Complexity is spiraling out of control
- Innovation is blocked by assumptions
- Same problem keeps recurring
- Scale or scope is uncertain
- Multiple approaches have failed

## Techniques

### Simplification Cascade
When complexity spirals: strip the problem to its simplest form, solve that, then add complexity back one layer at a time.

### Inversion Exercise
When constrained by assumptions: invert the problem. Instead of "how to make X faster," ask "what makes X slow?"

### Meta-Pattern Recognition
When patterns recur: look for the pattern behind the patterns. What structural issue causes this to keep happening?

### Scale Game
When scale is uncertain: solve for 1, then 10, then 1000. Where does the approach break?

## Rules

- Try the simplest approach first
- If stuck after 2 attempts, change strategy entirely
- Document what was tried and why it failed
- Ask "what would make this trivial?" before adding complexity
