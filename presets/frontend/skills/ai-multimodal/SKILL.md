# AI Multimodal

Activate this skill when working with images, documents, or multimedia content.

## When to Use

- Analyzing screenshots or design mockups
- Processing PDF documents for data extraction
- Generating images from text descriptions
- Comparing visual designs for differences
- Extracting text from images (OCR)

## Capabilities

- Image analysis: captioning, object detection, visual Q&A
- Document processing: PDF tables, forms, charts
- Image generation: text-to-image, editing, composition
- Video analysis: scene detection, temporal analysis
- Audio processing: transcription, summarization

## Rules

- Always verify generated content for accuracy
- Use appropriate model for the task complexity
- Handle large files with proper chunking
- Respect content licensing and attribution
- Validate extracted data against source
