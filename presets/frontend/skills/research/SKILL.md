# Research

Activate this skill when researching technologies, evaluating libraries, or finding best practices.

## When to Use

- Evaluating competing libraries or frameworks
- Finding official documentation for a technology
- Investigating best practices for a pattern
- Comparing approaches with trade-off analysis
- Checking compatibility and version requirements

## Process

1. Define the research question clearly
2. Search authoritative sources (official docs first)
3. Cross-reference multiple sources for accuracy
4. Evaluate applicability to the current project
5. Summarize findings with confidence levels
6. List unresolved questions

## Rules

- Prioritize official documentation over blog posts
- Note version numbers and compatibility
- Distinguish proven patterns from experimental ones
- Flag security concerns in dependencies
- Be honest about confidence levels
- Do NOT implement -- only research and report
