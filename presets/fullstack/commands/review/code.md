## Arguments
TARGET: $1 (default: staged changes)

## Workflow
1. Identify files to review (staged, branch diff, or specific file)
2. Analyze code quality, patterns, and potential issues
3. Check TypeScript strictness and type safety
4. Verify error handling and edge cases
5. Report findings categorized by severity
