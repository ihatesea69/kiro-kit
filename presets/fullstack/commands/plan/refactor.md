## Arguments
TARGET: $1 (required)

## Workflow
1. Analyze current code structure and pain points
2. Identify refactoring goals and constraints
3. Plan incremental steps (each step must leave code working)
4. Assess risk and identify test coverage gaps
5. Output plan to `plans/` directory
