description: Create a conventional commit with staged changes
inclusion: manual
argument-hint: "[type] [message]"
---

## Arguments
TYPE: $1 (default: inferred from changes)
MESSAGE: $2 (default: generated from diff)

## Workflow
1. Review staged changes
2. Determine commit type (feat, fix, refactor, docs, chore)
3. Generate descriptive commit message
4. Create commit with conventional format
5. Report commit hash and message
