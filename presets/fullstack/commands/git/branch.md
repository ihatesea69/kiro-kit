inclusion: manual

## Arguments
TYPE: $1 (required: feature, fix, refactor, chore)
DESCRIPTION: $2 (required)

## Workflow
1. Verify current branch is up to date
2. Create branch with format: `$1/$2` (kebab-case)
3. Switch to new branch
4. Report branch name and base
