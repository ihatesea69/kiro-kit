# Research

Activate when you need to investigate technologies, evaluate libraries, or gather technical information.

## When to Use

- Evaluating competing libraries or frameworks
- Finding official documentation for a technology
- Understanding best practices for a specific domain
- Investigating new APIs or services
- Comparing approaches with evidence

## Process

1. Define the research question clearly
2. Identify authoritative sources (official docs, RFCs, reputable blogs)
3. Cross-reference multiple sources for accuracy
4. Evaluate applicability to the current project context
5. Summarize findings with recommendations

## Quality Standards

- Prioritize official documentation over blog posts
- Note version numbers and publication dates
- Distinguish between stable and experimental features
- Be explicit about what is unknown or uncertain
- Provide actionable recommendations, not just information
