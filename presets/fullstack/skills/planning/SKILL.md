# Planning

Activate when creating implementation plans, evaluating architectures, or decomposing complex features.

## When to Use

- Starting a new feature that spans multiple files/modules
- Evaluating architectural approaches
- Breaking down epics into implementable tasks
- Estimating effort and identifying dependencies
- Creating phased delivery plans

## Process

1. Define the problem and success criteria
2. Identify constraints (time, team, technology)
3. Research relevant patterns and prior art
4. Decompose into phases with clear deliverables
5. Identify risks and dependencies
6. Create prioritized task list

## Output Structure

- Problem statement and constraints
- Evaluated approaches with trade-offs
- Recommended approach with rationale
- Phased implementation plan
- Risk assessment and mitigations
- Success criteria for each phase

## Principles

- YAGNI: do not plan for features not yet needed
- KISS: prefer simple solutions over clever ones
- Incremental delivery: working software at each phase
- Reversible decisions: prefer approaches that are easy to change
