# Code Review

Activate when receiving code review feedback, completing tasks requiring review, or before making completion claims.

## Practices

### Receiving Feedback
- Evaluate feedback with technical rigor
- Do not agree performatively -- verify claims
- Ask for clarification on unclear suggestions
- Prioritize correctness over politeness

### Requesting Reviews
- Provide context: what changed and why
- Highlight areas of uncertainty
- Include test results and verification steps
- Note any trade-offs or known limitations

### Verification Gates
- Do not claim completion without evidence
- Run tests and show passing output
- Verify the change works in context (not just in isolation)
- Check for regressions in related functionality
