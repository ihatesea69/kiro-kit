# Sequential Thinking

Activate for complex problems requiring step-by-step analysis with the ability to revise earlier conclusions.

## When to Use

- Complex problem decomposition
- Adaptive planning that may need course correction
- Analysis where initial assumptions may be wrong
- Problems with unclear scope requiring exploration
- Multi-step solutions with dependencies

## Process

1. Break the problem into numbered thought steps
2. For each step, state what you know and what you are assuming
3. After each step, evaluate whether previous steps need revision
4. If a step reveals new information, revise earlier conclusions
5. Continue until you reach a verified conclusion

## Rules

- Number each thought step explicitly
- State assumptions clearly at each step
- Mark revisions when earlier steps are updated
- Do not skip steps to reach conclusions faster
- Verify final conclusion against all steps
