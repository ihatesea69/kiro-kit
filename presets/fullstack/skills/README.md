# Skills

Skills provide specialized knowledge and workflows that agents can activate on demand. Each skill has a `SKILL.md` with front-matter metadata and activation instructions.

## Structure

Each skill folder contains:
- `SKILL.md` - Main skill file with front-matter and instructions
- `references/` - Detailed documentation (loaded on demand)
- `scripts/` - Automation scripts (optional)
- `assets/` - Static assets (optional)
