# Problem Solving

Activate when stuck on complex problems, facing innovation blocks, or dealing with recurring patterns.

## Techniques

### Simplification Cascade
When complexity spirals: remove features until the core works, then add back one at a time.

### Collision-Zone Thinking
When innovation is blocked: combine two unrelated concepts to find novel solutions.

### Meta-Pattern Recognition
When patterns recur: identify the underlying pattern and solve at a higher abstraction level.

### Inversion Exercise
When constrained by assumptions: invert the problem. Ask "what if the opposite were true?"

### Scale Game
When uncertain about scale: solve for 1 user, 100 users, 10000 users. See where the design breaks.

## When to Dispatch

- Stuck for more than 15 minutes on the same approach
- Third attempt at the same fix without progress
- Solution feels overly complex for the problem size
- Requirements seem contradictory
