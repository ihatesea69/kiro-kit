# Fullstack Preset

Comprehensive kit for Next.js/T3 stack development combining frontend and backend capabilities with payment integration and e-commerce support.

## Target Stack

- Next.js App Router (React Server Components, Server Actions)
- TypeScript strict mode
- tRPC or REST API routes
- Prisma/Drizzle ORM with PostgreSQL
- Authentication (NextAuth.js / Better Auth)
- Tailwind CSS + shadcn/ui
- Stripe / Polar / SePay payment integration
- Shopify integration (optional)

## Included Artifacts

- 20 agents (fullstack-developer, api-developer, database-architect, performance-optimizer, + 16 baseline)
- 22 skills (frontend + backend + shopify + payment-integration)
- 29 commands (baseline + fullstack category)
- 8 hooks (cross-platform with .js/.sh/.ps1 variants)
- 4 workflows (always-on development guides)
- 2 steering files (fullstack conventions, Next.js App Router)
- Spec templates for fullstack features
- Docs templates (code standards, architecture, roadmap)
- MCP server configurations (filesystem, git, playwright, fetch, docs-seeker, postgres)

## Usage

```bash
npx kiro-kit init --preset fullstack
```

## Recommended For

- SaaS applications with Next.js
- E-commerce platforms (Shopify storefront + custom backend)
- Full-stack TypeScript monorepos
- T3 stack projects (Next.js + tRPC + Prisma + Tailwind)
- Applications requiring payment processing
