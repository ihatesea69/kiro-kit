## Arguments
SCOPE: $1 (required, what to refactor)

## Workflow
1. Analyze current code structure and dependencies
2. Identify affected modules and tests
3. Design target architecture
4. Plan migration steps (incremental, not big-bang)
5. Identify risks and rollback strategy
6. Create task breakdown
7. Save plan to `plans/` directory
