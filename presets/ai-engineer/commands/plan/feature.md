description: Plan a new data/ML feature with research and task breakdown
inclusion: manual
argument-hint: "[feature-description]"
---

## Arguments
FEATURE: $1 (required, description of the feature)

## Workflow
1. Research existing solutions and approaches
2. Define success metrics and acceptance criteria
3. Identify data requirements and availability
4. Design approach with clear milestones
5. Create task breakdown with estimates
6. Document risks and compute requirements
7. Save plan to `plans/` directory
