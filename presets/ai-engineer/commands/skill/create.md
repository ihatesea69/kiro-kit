## Arguments
NAME: $1 (required, skill name in kebab-case)
DOMAIN: $2 (required, domain area for the skill)

## Workflow
1. Research the domain for key concepts and patterns
2. Define activation triggers (when should this skill activate?)
3. Structure knowledge into concise instructions
4. Create SKILL.md with front-matter
5. Add references/ if domain is complex
6. Test activation with sample prompts
7. Update skills/README.md
