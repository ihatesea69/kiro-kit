inclusion: manual

## Arguments
RUNS: $1 (required, comma-separated run IDs or experiment names)

## Workflow
1. Load experiment metadata for specified runs
2. Compare hyperparameters across runs
3. Compare metrics (accuracy, loss, F1, etc.)
4. Identify best performing configuration
5. Generate comparison table and visualizations
6. Recommend which model to promote
