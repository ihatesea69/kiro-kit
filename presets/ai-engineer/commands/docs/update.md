inclusion: manual

## Arguments
SCOPE: $1 (default: all, options: all, api, architecture, readme)

## Workflow
1. Identify recent code changes (git diff or file timestamps)
2. Determine which documentation needs updating
3. Update API documentation for changed modules
4. Update architecture docs if structure changed
5. Verify all code examples still work
6. Report documentation changes made
