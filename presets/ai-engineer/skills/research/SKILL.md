# Research

Activate this skill when researching ML techniques, evaluating data tools, or finding best practices.

## When to Use

- Evaluating competing ML frameworks or libraries
- Finding official documentation for data tools
- Investigating algorithm implementations and trade-offs
- Comparing model architectures for a use case
- Checking dataset licenses and availability

## Process

1. Define the research question clearly
2. Search authoritative sources (papers, official docs first)
3. Cross-reference multiple sources for accuracy
4. Evaluate applicability to the current project
5. Summarize findings with confidence levels
6. List unresolved questions

## Rules

- Prioritize official documentation and peer-reviewed papers
- Note version numbers and compatibility (Python, CUDA)
- Distinguish proven methods from experimental ones
- Flag computational requirements and hardware needs
- Be honest about confidence levels
- Do NOT implement -- only research and report
