# Implementation Plan: AWS-Native RAG Knowledge Assistant

## Overview

This plan produces infrastructure-as-code artifacts, agent source files, a golden question set, an evaluation pipeline, and observability configuration — in dependency order: CDK app scaffolding, storage and vector store provisioning, Knowledge Base and chunking configuration, Guardrails stack, Strands Agents query front end, golden question set and validation, evaluation CI quality gate, drift monitoring, static analysis gates, sandbox end-to-end verification, and final documentation. Sub-tasks marked `- [ ]*` are test and validation gates that must pass before the artifact is considered complete. Estimated effort: 6–8 engineer-days for a single AI engineer.

Requirement references use the format `RN.M` (Requirement N, Acceptance Criterion M).

  - [ ] 8.1 Create `evaluation/thresholds.json` with the eight metric thresholds: `context_relevance: 0.80`, `coverage: 0.75`, `citation_precision: 0.85`, `citation_coverage: 0.80`, `correctness: 0.80`, `completeness: 0.75`, `faithfulness: 0.85`, `helpfulness: 0.80`; commit this file to version control so threshold changes are tracked in code review.
  - [ ] 8.2 Implement `src/ci/eval_gate.py`: call `bedrock.create_evaluation_job` with `evaluationConfig.ragConfig.knowledgeBaseConfig.type = "KNOWLEDGE_BASE"`, the staging Knowledge Base ID, golden question set S3 URI, and judge model `arn:aws:bedrock:us-east-1::foundation-model/amazon.nova-pro-v1:0`; poll every 60 seconds; enforce 30-minute timeout; parse evaluation output from S3; call `assert_thresholds` against `evaluation/thresholds.json`; exit non-zero on any breach, printing a breach table.
  - [ ] 8.3 In `infra/stacks/agent_stack.py`, provision a Step Functions `aws_stepfunctions.StateMachine` (`eval-orchestrator`) that orchestrates: (1) invoke `kb-eval-validator` Lambda, (2) call `CreateEvaluationJob` via an SDK integration step, (3) wait 60 seconds (`aws_stepfunctions.Wait`), (4) call `GetEvaluationJob` and branch on status — loop back to step 3 if `IN_PROGRESS`, succeed if `COMPLETED`, fail if `FAILED` or elapsed > 30 minutes; grant the state machine `bedrock:CreateEvaluationJob`, `bedrock:GetEvaluationJob`, `bedrock:StopEvaluationJob`.
