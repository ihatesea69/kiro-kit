# Implementation Plan: General-Purpose Support Chatbot on Amazon Bedrock AgentCore

## Overview

This plan builds the support chatbot end-to-end — from Terraform module scaffolding through to a passing LLM-as-a-Judge evaluation gate — in dependency order: Guardrail and Memory resources first (no application dependencies), then the order-lookup Lambda and AgentCore Gateway, then the Strands Agents implementation and container, then the AgentCore Runtime deployment, and finally integration verification and documentation. Sub-tasks marked `- [ ]*` are test or validation gates that must pass before the parent task is considered complete. Estimated effort: 6–8 engineer-days for a single AI engineer. Requirement references use the format `RN.M` (Requirement N, Acceptance Criterion M).
