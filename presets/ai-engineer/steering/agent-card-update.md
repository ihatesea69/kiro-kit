# Agent Card Update

Run on demand to refresh the agent card with tools, guardrails, eval results, limitations, and cost.

Update (or create) the agent card: agent name and version, model id and provider, deployment target (AgentCore Harness / Runtime / Lambda), the full tool inventory with each tool's data access, memory tiers used and their retention, guardrail configuration, latest evaluation results against evals/thresholds.yaml, known limitations and failure modes, cost per conversation, and the escalation path to a human. Pull metrics from the most recent eval report where available.
