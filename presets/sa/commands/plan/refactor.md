## Arguments
TARGET: $1 (required)

## Workflow
1. Analyze current state of target area
2. Identify pain points and technical debt
3. Design target architecture
4. Plan migration steps with rollback points
5. Estimate effort and risk
6. Output plan to `plans/` directory
