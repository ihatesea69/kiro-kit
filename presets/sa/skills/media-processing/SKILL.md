# Media Processing

Activate this skill when you need to manipulate media files.

## When to Use

- Converting media formats (video, audio, image)
- Resizing, cropping, or optimizing images
- Encoding video with specific codecs
- Extracting audio from video
- Batch processing media files
- Creating thumbnails or previews

## Tools

- FFmpeg: video/audio encoding, conversion, streaming
- ImageMagick: image manipulation, format conversion, effects

## Rules

- Use appropriate codecs for the target platform
- Optimize for file size vs quality trade-off
- Preserve metadata when appropriate
- Test output on target devices/browsers
- Use hardware acceleration when available
