# Docs Seeker

Activate this skill when you need to find and reference technical documentation.

## When to Use

- Looking up API references for a library or framework
- Finding configuration options for a tool
- Checking compatibility or version requirements
- Understanding best practices from official sources
- Verifying behavior described in documentation

## Process

1. Identify the technology and version
2. Search official documentation sources
3. Check llms.txt and context7.com for AI-friendly docs
4. Extract relevant sections
5. Summarize findings with source links

## Rules

- Always prefer official documentation over third-party sources
- Include version numbers in all references
- Verify information is current (check publish dates)
- Provide direct links to source material
- Note when documentation is incomplete or ambiguous
