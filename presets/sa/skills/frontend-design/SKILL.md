# Frontend Design

Activate this skill when creating UI components or pages that need visual design decisions.

## When to Use

- Building monitoring dashboards or admin panels
- Creating status pages or deployment UIs
- Designing configuration interfaces
- Implementing responsive layouts

## Design Principles

- Mobile-first responsive design
- Visual hierarchy through typography and spacing
- Consistent spacing using 4px/8px grid system
- Accessible color contrast (WCAG 2.1 AA minimum)
- Progressive disclosure of complex information

## Rules

- Use semantic HTML elements for structure
- Ensure 4.5:1 contrast ratio for normal text
- Touch targets minimum 44x44px on mobile
- Respect prefers-reduced-motion for animations
- Test across breakpoints before considering complete
- Never use color as the sole indicator of state
