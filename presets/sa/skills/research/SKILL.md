# Research

Activate this skill when you need to investigate technologies, evaluate options, or gather information before making decisions.

## When to Use

- Evaluating competing technologies or approaches
- Investigating unfamiliar tools or frameworks
- Gathering best practices for a specific domain
- Comparing cloud services or infrastructure options
- Understanding security implications of a choice

## Process

1. Define the research question clearly
2. Identify authoritative sources (official docs, RFCs, benchmarks)
3. Gather data from multiple sources
4. Cross-reference for accuracy
5. Evaluate trade-offs in context of the project
6. Synthesize into actionable recommendations

## Rules

- Prioritize official documentation over blog posts
- State confidence level for each finding
- Distinguish proven patterns from experimental approaches
- Include version numbers and compatibility notes
- Flag security concerns in recommendations
- Do NOT implement -- only research and report
