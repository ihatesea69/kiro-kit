# Frontend Development

Activate this skill when implementing mobile UI components and screens.

## When to Use

- Building new screens or features
- Implementing complex layouts and animations
- Creating reusable widget/component libraries
- Integrating UI with state management
- Implementing platform-adaptive interfaces

## Flutter UI Development

- Use Material 3 or Cupertino widgets based on platform
- Implement responsive layouts with LayoutBuilder/MediaQuery
- Use CustomScrollView with slivers for complex scrolling
- Implement Hero animations for screen transitions
- Use AnimatedBuilder for custom animations
- Keep widget trees shallow (extract sub-widgets)

## React Native UI Development

- Use platform-adaptive components
- Implement responsive layouts with Dimensions/useWindowDimensions
- Use FlatList/SectionList for performant lists
- Implement Reanimated for smooth animations
- Use StyleSheet.create for optimized styles

## Quality Standards

- All UI must handle loading, error, and empty states
- Responsive across phone and tablet form factors
- Support both portrait and landscape orientations
- Keyboard avoidance for input screens
- Proper safe area handling (notches, home indicators)
- Smooth scrolling at 60fps
