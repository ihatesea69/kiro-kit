# Docs Seeker

Activate this skill when you need to find and retrieve technical documentation.

## When to Use

- Looking up Flutter/Dart API documentation
- Finding React Native component references
- Checking platform-specific API guides (iOS, Android)
- Retrieving package documentation from pub.dev or npm
- Finding migration guides for version upgrades

## Process

1. Identify the specific documentation needed
2. Search official sources first (flutter.dev, reactnative.dev)
3. Check package-specific documentation
4. Retrieve relevant sections
5. Summarize key findings for the task at hand

## Sources Priority

1. Official framework documentation
2. Package README and API docs
3. Platform developer documentation (developer.apple.com, developer.android.com)
4. GitHub repository documentation
5. Community resources (verified accuracy)

## Rules

- Always prefer official documentation over third-party
- Note the version the documentation applies to
- Flag deprecated APIs or patterns
- Provide direct references when possible
