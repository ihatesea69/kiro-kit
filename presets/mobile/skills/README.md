# Skills Directory

This directory contains skills that extend agent capabilities with specialized knowledge for mobile development.

## Structure

Each skill is a directory containing:
- `SKILL.md` - Main skill file with front-matter (name, description) and guidelines
- `references/` - Optional reference documentation
- `scripts/` - Optional executable scripts
- `assets/` - Optional static assets

## Available Skills

### Mobile-Specific
- `mobile-development` - Flutter and React Native development patterns
- `ai-multimodal` - Multimedia content processing and generation
- `ui-styling` - Platform-adaptive styling and theming
- `flutter-state` - Flutter state management (BLoC, Riverpod, Provider)
- `mobile-testing` - Widget tests, integration tests, golden tests
- `offline-first` - Offline-first architecture and sync strategies
- `app-deployment` - App Store and Google Play deployment
- `native-integration` - Platform channels and native modules

### General Development
- `debugging` - Systematic debugging framework
- `sequential-thinking` - Structured problem-solving
- `problem-solving` - Techniques for complex challenges
- `planning` - Implementation planning
- `research` - Technical research and evaluation
- `docs-seeker` - Documentation retrieval
- `repomix` - Repository packaging for analysis
- `media-processing` - Image and video processing
- `code-review` - Code review practices
- `skill-creator` - Creating new skills
- `template-skill` - Skill template
- `mcp-builder` - Building MCP servers
- `mcp-management` - Managing MCP integrations
- `frontend-design` - Mobile UI design
- `frontend-development` - Mobile UI implementation
- `chrome-devtools` - Browser automation
- `web-frameworks` - Companion web applications
