# Frontend Design

Activate this skill when creating mobile UI that requires high visual quality and design thinking.

## When to Use

- Building new screens or features that need visual design decisions
- Creating widget libraries or design systems
- Implementing responsive layouts for multiple form factors
- Designing interactive elements with proper states and transitions
- Reviewing existing UI for design improvements

## Design Principles

- Platform-native feel (iOS HIG, Material Design 3)
- Visual hierarchy through typography, spacing, and color
- Consistent spacing using 4px/8px grid system
- Purposeful use of whitespace for readability
- Progressive disclosure of complex information
- Accessible color contrast (WCAG 2.1 AA minimum)

## Implementation Guidelines

- Use platform-native components as foundation
- Implement proper focus states for accessibility
- Add hover/press states for interactive elements
- Use platform-appropriate transitions (300ms max)
- Respect reduced motion preferences
- Test across screen sizes before considering complete

## Quality Standards

- Minimum 44pt touch targets
- 4.5:1 contrast ratio for normal text
- 3:1 contrast ratio for large text and UI elements
- Support dark mode and dynamic type
- Never use color as sole indicator of state
