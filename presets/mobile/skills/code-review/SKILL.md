# Code Review

Activate this skill when receiving or providing code review feedback.

## When to Use

- Receiving code review feedback
- Completing tasks requiring review before proceeding
- Before making completion claims about implementations
- When reviewing pull requests

## Practices

- Receive feedback with technical rigor over performative agreement
- Request reviews via code-reviewer agent
- Apply verification gates requiring evidence before status claims
- Never claim completion without running tests and verifying behavior

## Rules

- Every critique must be evaluated on technical merit
- Distinguish blocking issues from suggestions
- Provide evidence (test results, build output) with completion claims
- Do not dismiss feedback without technical justification
- Fix issues before marking work as complete
