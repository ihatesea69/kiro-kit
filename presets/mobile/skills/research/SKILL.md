# Research

Activate this skill when you need to investigate technologies, evaluate options, or gather technical information.

## When to Use

- Evaluating packages or libraries for a specific need
- Investigating platform API capabilities
- Comparing architectural approaches
- Understanding new framework features
- Assessing security implications of dependencies

## Process

1. Define research questions clearly
2. Search official documentation first
3. Check package registries (pub.dev, npm) for health metrics
4. Cross-reference multiple sources
5. Evaluate trade-offs and compatibility
6. Synthesize into actionable recommendation

## Rules

- Prefer official documentation over blog posts
- Verify information currency (check dates)
- Note version compatibility requirements
- Distinguish stable from experimental features
- Document sources for future reference
- Do NOT implement -- only research and recommend
