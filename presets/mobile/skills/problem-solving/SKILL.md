# Problem Solving

Activate this skill when facing complex problems that resist straightforward solutions.

## When to Use

- Complexity spirals (solution keeps growing)
- Innovation blocks (cannot find a good approach)
- Recurring patterns (same problem keeps appearing)
- Assumption constraints (stuck due to false assumptions)
- Scale uncertainty (unsure how solution will scale)

## Techniques

- Simplification cascade: strip to minimum viable solution
- Collision-zone thinking: combine unrelated ideas
- Meta-pattern recognition: identify the pattern behind patterns
- Inversion exercise: assume the opposite of constraints
- Scale game: test solution at 10x and 0.1x scale

## Rules

- Try simplification first before adding complexity
- Question every assumption explicitly
- If stuck for more than 2 attempts, try a fundamentally different approach
- Document what was tried and why it failed
- Prefer reversible decisions over perfect decisions
