# Chrome DevTools

Activate this skill for browser automation and web view debugging.

## When to Use

- Capturing screenshots of web-based designs for reference
- Debugging WebView content in mobile apps
- Automating browser-based testing workflows
- Analyzing web performance for hybrid apps
- Scraping design references from websites

## Capabilities

- Launch and control browser instances
- Capture full-page and element screenshots
- Monitor network traffic and performance
- Execute JavaScript in page context
- Automate form filling and navigation

## Mobile-Specific Usage

- Test responsive layouts at mobile viewport sizes
- Debug OAuth flows that use web views
- Capture design inspiration screenshots
- Test PWA behavior and service workers
- Verify deep link handling in web contexts

## Rules

- Use headless mode for CI/automated tasks
- Set appropriate viewport sizes for mobile testing
- Handle timeouts gracefully
- Clean up browser instances after use
