## Arguments
TARGET: $1 (default: staged changes, or specific file/branch)

## Workflow
1. Identify changed files and their scope
2. Review for correctness, bugs, and edge cases
3. Check platform-specific conventions (Dart style, RN patterns)
4. Verify error handling and resource cleanup
5. Check accessibility compliance
6. Report findings grouped by severity
