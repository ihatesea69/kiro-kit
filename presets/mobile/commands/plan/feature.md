---
description: Create an implementation plan for a new mobile feature
inclusion: manual
argument-hint: "[feature-name]"
---

## Arguments
FEATURE: $1 (required, name of the feature to plan)

## Workflow
1. Define feature requirements and success criteria
2. Identify affected layers (UI, logic, data, platform)
3. Decompose into implementable tasks (30min-2hr each)
4. Identify platform-specific considerations
5. Assess risks and dependencies
6. Generate plan in `plans/YYYYMMDD-HHmm-$1/`
