## Arguments
SCREEN: $1 (required, name of the screen to wireframe)

## Workflow
1. Define screen purpose and user goals
2. Map content hierarchy and information architecture
3. Specify layout structure (safe areas, scroll behavior)
4. Define interaction patterns (gestures, transitions)
5. Note platform-specific adaptations (iOS vs Android)
6. Document accessibility requirements
