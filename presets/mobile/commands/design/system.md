## Arguments
SCOPE: $1 (default: all, options: all, colors, typography, spacing, components)

## Workflow
1. Analyze existing theme configuration (ThemeData, StyleSheet)
2. Document design tokens (colors, typography scale, spacing grid)
3. List reusable components with their variants
4. Generate visual reference documentation
5. Identify inconsistencies or missing tokens
