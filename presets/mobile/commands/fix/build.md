---
description: Diagnose and fix build failures for mobile platforms
inclusion: manual
argument-hint: "[platform]"
---

## Arguments
PLATFORM: $1 (default: all, options: all, ios, android, web)

## Workflow
1. Run build and capture error output
2. Analyze error messages and identify root cause
3. Check common issues (SDK version, dependencies, signing)
4. Apply fix and verify build succeeds
5. Document the issue and resolution
