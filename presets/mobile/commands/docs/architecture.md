## Arguments
LAYER: $1 (default: all, options: all, presentation, domain, data, platform)

## Workflow
1. Analyze project structure and module dependencies
2. Document architectural layers and their responsibilities
3. Map data flow between layers
4. Document navigation architecture
5. Note platform-specific architectural decisions
6. Generate dependency diagram description
