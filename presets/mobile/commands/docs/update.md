## Arguments
SCOPE: $1 (default: all, options: all, api, architecture, setup)

## Workflow
1. Identify recent code changes (git diff)
2. Determine which documentation is affected
3. Update relevant documentation files
4. Verify code examples still compile
5. Update table of contents and cross-references
