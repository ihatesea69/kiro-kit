# Third-Party Notices

This file lists third-party content included in or referenced by skills in this directory.

## Attributions

No third-party content is currently included in the baseline template. When adding skills that reference external documentation, APIs, or code, add attribution entries here.

## Format

```
## [Package/Content Name]
- Source: [URL]
- License: [License type]
- Usage: [How it is used in this skill]
```

## License Compliance

When adding third-party content to skills:
- Verify the license permits redistribution
- Add an entry to this file
- Include license text in the skill's `references/` folder if required
- Do not include content under restrictive licenses without explicit permission
