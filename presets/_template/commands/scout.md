## Arguments
QUERY: $1 (required)
SCALE: $2 (default: 3)

## Workflow
1. Analyze the search query to identify relevant directories
2. Search codebase in parallel for matching files
3. Synthesize results into organized file list
4. Report relevant files grouped by category
