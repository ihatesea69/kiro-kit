---
description: Plan a refactoring effort for a module or pattern
inclusion: manual
argument-hint: "[target]"
---

## Arguments
TARGET: $1 (required)

## Workflow
1. Analyze current implementation of the target
2. Identify code smells and improvement opportunities
3. Plan refactoring steps with minimal disruption
4. Define verification criteria (tests must pass)
5. Output refactoring plan
