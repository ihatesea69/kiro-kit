Kiro-Kit is a CLI that bootstraps an engineer-grade [Kiro](https://kiro.dev) workspace
in one command. Pick a preset for your stack and get agents, skills, commands, hooks,
MCP server config, and spec scaffolding written straight into `.kiro/`.

```bash
npx kiro-kit init
```

Every preset is **self-contained** — installing one never requires another, and
removing one has no side effects on the rest.

## Why presets

A preset is a collection of Kiro configuration files targeting one development
context — frontend, backend, mobile, devops, data/AI, and more. Rather than
assembling agents and commands by hand, you install a curated set that already
knows the idioms of your stack.

The [reference section](/docs/reference) is generated directly from the preset
manifests in the repository, so the catalog you read here is the catalog that
ships.
